## 🌟 ما هو أوبن سوريا؟

**أوبن سوريا (SYL)** هي العملة الرقمية الخاصة بسوريا - مثل بيتكوين، لكنها صُنعت خصيصاً للشعب السوري.

فكّر فيها كأموال رقمية:
- 🔒 **لا يمكن لأي حكومة أو بنك التحكم بها**
- 🌍 **تعمل في أي مكان** في العالم عبر الإنترنت
- 💸 **أرسل المال فوراً** لعائلتك في الخارج برسوم منخفضة
- 🏦 **أنت تتحكم بأموالك** - لا حاجة لحساب بنكي
- 💻 **أي شخص يمكنه التعدين** بحاسوب عادي

## 💻 للمطورين والمُعدّنين

### متطلبات النظام
- **نظام التشغيل:** Linux أو macOS أو Windows
- **الذاكرة:** 4GB كحد أدنى (8GB مُوصى به)
- **التخزين:** 10GB مساحة فارغة

### البناء من المصدر

```bash
# 1. استنساخ المستودع
git clone https://github.com/opensyria/SYL.git
cd SYL

# 2. البناء
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)

# 3. تشغيل العقدة
./build/bin/opensyd -daemon

# 4. التحقق من العمل
./build/bin/opensy-cli getblockchaininfo
```

## ⛏️ التعدين (اربح SYL)

### لماذا تُعدّن أوبن سوريا؟
- **عادل للجميع** - يستخدم معالج حاسوبك العادي
- **لا حاجة لمعدات باهظة** - لا حاجة لآلات تعدين خاصة
- **اربح 10,000 SYL** لكل كتلة تُعدّنها

### ابدأ التعدين في 3 خطوات

```bash
# الخطوة 1: إنشاء محفظة
./build/bin/opensy-cli createwallet "mywallet"

# الخطوة 2: احصل على عنوان التعدين
./build/bin/opensy-cli getnewaddress "mining"
# احفظ هذا العنوان! يبدو مثل: syl1qxxxxxxxxx...

# الخطوة 3: ابدأ التعدين
./build/bin/opensy-cli generatetoaddress 1 YOUR_ADDRESS_HERE
```

> 💡 **نصيحة:** اترك التعدين يعمل طوال الليل لفرص أفضل!

### دليل معدات التعدين

| حاسوبك | هل يمكنك التعدين؟ | الأداء |
|--------|------------------|--------|
| لابتوب عادي (4 نوى) | ✅ نعم | مبتدئ |
| حاسوب ألعاب (8+ نوى) | ✅ نعم | جيد |
| خادم (32+ نوى) | ✅ نعم | ممتاز |

### متطلبات الذاكرة

> ⚠️ **مهم:** تعدين RandomX (الكتل 210,000+) يحتاج ذاكرة كبيرة.

| الوضع | الذاكرة المطلوبة | سرعة التجزئة | متى تستخدمه |
|-------|-----------------|-------------|-------------|
| **مجموعة بيانات كاملة** | 2.5GB حرة | 100% | مُوصى به للتعدين |
| **الوضع الخفيف** | 256MB | ~10% | الأنظمة محدودة الذاكرة |

**لاستخدام الوضع الخفيف** (أبطأ لكن يعمل على أي نظام):
```bash
opensyd -randomxlightmode
```

**توصيات المعالج:**
- معالج x86_64 مع دعم تعليمات AES-NI
- نوى أكثر = تعدين أسرع
- ARM64 مدعوم لكن أبطأ

## 🪙 رموز SRC-20

يدعم أوبن سوريا الرموز الأصلية عبر معيار **SRC-20**. يمكن لأي شخص إصدار رموز على سلسلة أوبن سوريا!

### تتبع الرموز (مدمج)

تتبع الرموز مفعّل تلقائياً على جميع عقد أوبن سوريا - لا حاجة لأي إعدادات. فقط شغّل العقدة واستخدم أوامر الرموز!

```bash
# شغّل العقدة - تتبع الرموز تلقائي
opensyd
```

### أوامر الرموز

```bash
# عرض جميع الرموز
opensy-cli listtokens

# معلومات رمز
opensy-cli gettokeninfo <token_id>

# إصدار رمز خاص بك
opensy-cli issuetoken "SYM" "اسم الرمز" 1000000 8

# تحويل رموز
opensy-cli transfertoken <token_id> <to_address> <amount>
```

📖 راجع [doc/src20-spec.md](doc/src20-spec.md) للمواصفات الكاملة.

**كيف أحصل على SYL؟**
- عدّنها بنفسك (مجاناً، تستخدم حاسوبك)
